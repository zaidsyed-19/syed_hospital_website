# Syed Hospital website

Coming Soon landing page for Syed Hospital, Hubballi, Karnataka. Built with Next.js and ready for Vercel's standard Next.js deployment.

## Local setup

Install dependencies with `npm install`, then run `npm run dev` and open `http://localhost:3000`.

## Drone footage

Add video and poster files to `public/media/`. See [public/media/README.md](public/media/README.md) for exact names and recommendations. The video is optional; the hero poster is the graceful fallback.

## Contact configuration

Set the actual hospital phone and WhatsApp contact in `src/lib/site.ts` before publishing. The current source intentionally leaves both values empty rather than inventing a number.
