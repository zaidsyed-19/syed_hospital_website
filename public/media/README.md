# Future drone footage

Place optimized, silent, looping hero footage in this folder:

- `public/media/hospital-drone.mp4` (H.264 MP4; preferred broad compatibility)
- `public/media/hospital-drone.webm` (optional smaller WebM alternative)
- `public/media/hospital-drone-poster.svg` (current cinematic illustrated fallback; replace with your own approved still if desired)

The hero references `/media/hospital-drone.mp4`, `/media/hospital-drone.webm`, and `/media/hospital-drone-poster.svg`. Keep the MP4 reasonably compressed (ideally 8–15 seconds, 1080p, no audio). The page starts with the poster if the video files are not present. Autoplay is muted, inline, and looping; reduced-motion users and narrow screens use the poster instead.
